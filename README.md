One post on X promoting make.fun's make-your-own-bounty post: the post quotes make.fun's post with a photo of its own, carries make.fun and the entrant's play code in its text, and this repository hands in the post's address in POST.json. Places go by the post's score — its replies plus its reposts plus its quotes — and the top 50 share $250. main.ts copies POST.json from the repository to /output/POST.json, where the gate reads it; that is all the program does.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
